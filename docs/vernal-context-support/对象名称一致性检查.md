## 五、业务逻辑一致性检查（路线图完成后的目标状态）

### ✅ 完全一致的逻辑（路线图完成后）

- **缓存抽象**：get / put / evict / clear / lookup 语义一致
- **事务感知缓存**：put/evict/clear 延迟到 after-commit；无事务立即执行
- **Caffeine 缓存**：dynamic 模式 / static 模式 / async 模式三态支持
- **JCache 缓存**：cache.put / cache.get / cache.remove 语义一致
- **Quartz 调度**：start / pause / resume / shutdown 四态；CronTrigger 表达式
- **JavaMail 邮件**：SMTP 发送 / 附件 / HTML 邮件 / 多收件人
- **FreeMarker 模板**：模板路径加载 / 变量替换 / 渲染

### 🔶 形态不同的逻辑

| 维度 | Spring | vernal |
|------|--------|--------|
| AOP 拦截器 | 19 个细粒度拦截器类 | 合并为 1 个通用 `JCacheInterceptor` |
| Cache 注解 | `@CacheResult` / `@CachePut` 等运行时注解 | `#[cache_result]` / `#[cache_put]` 过程宏（编译期） |
| Quartz 集群 | JDBC 集群 / RMI 集群 | 仅单机模式（tokio-cron-scheduler 限制） |
| JavaMail Session | JNDI 绑定 / Properties 绑定 | 直接构造 lettre::SmtpTransport |
| FreeMarker 语法 | `${var}` / `<#if>` | tera `{{ var }}` / `{% if %}` |

### ❌ 不实现的逻辑

- Quartz JDBC JobStoreTX / JobStoreCMT 集群模式
- Quartz RMI RemoteScheduler
- JavaMail JNDI Session 绑定
- JCache 完整 JSR-107 规范（仅核心接口）
- JCache AOP Advisor / Pointcut（用 vernal-aop trait 替代）

## 六、命名一致性规范

### 命名规则

| 项目 | 规范 | 示例 |
|------|------|------|
| Java 类名 | PascalCase | `TransactionAwareCacheDecorator` |
| Rust 文件名 | snake_case | `transaction_aware_cache_decorator.rs` |
| Java 接口 | 以 `I` 开头？不，Spring 不带 I 前缀 | `MailSender` |
| Rust trait | 不带 `I` 前缀 | `MailSender` trait |
| Java 包 | 全小写点分 | `org.springframework.cache.transaction` |
| Rust 模块 | 全小写下划线 | `cache::transaction` |
| Java 方法 | camelCase | `getName()` |
| Rust 方法 | snake_case | `get_name()` |
