# spring-context-support → vernal-context-support 对象级对照表（验收清单）

基线：Spring Framework **7.0.8**，spring-context-support 共 **80 个 Java 业务类**
（去除 7 个 `package-info.java`）。
本文档与 `语义迁移对照表.md` 互补：语义表回答"功能有没有"，
本表回答"**每个 Java 对象落在哪个 Rust 文件**"，是结构拆分与补缺的验收清单。

## 命名与组织规则

1. 目录、文件名一律 snake_case；类型 PascalCase；方法 snake_case
2. **每个 .rs 文件只对应一个 Java 对象**；接口去 Java 匈牙利前缀
3. `mod.rs` 只做模块声明与 re-export，**禁止定义任何类型/逻辑**
4. Java 多层嵌套包只要求**最后一层目录**完全对齐（如 `cache.jcache.interceptor.*`）
5. 每个文件头部必须有中文 doc 注释：说明对应 Java 类的全限定名、核心职责
6. 方法级中文注释从 Java 源码同步翻译
7. **公开 API 全部走 trait 抽象**：不暴露 moka / cacache / tokio-cron-scheduler / lettre / tera 的具体类型
8. **可选模块化**：scheduler / mail / ui.freemarker 通过 feature flag 控制（避免不必要的依赖）
