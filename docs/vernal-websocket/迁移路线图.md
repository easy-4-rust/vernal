# spring-websocket → vernal-websocket 迁移路线图

> 版本：v4.0（2026-07-27，与代码同步）
> 上游基线：本地 Spring Framework `spring-websocket` 源码

以 Spring WebSocket 的可观察行为为迁移基线，实现 Vernal 的异步 Rust WebSocket 能力。

## 四、已实现的核心语义（照原 Spring 实现，未简化）

- ConcurrentWebSocketSessionDecorator：双锁（flush_lock tryLock + buffer_lock），tryLock 失败时消息入 buffer，check_session_limits，OverflowStrategy Terminate/Drop，close 时 SESSION_NOT_RELIABLE 升级
- WebSocketHttpRequestHandler：返回完整 HTTP 响应（状态码 + headers + body + session），101/403/500
- SubProtocolWebSocketHandler：session registry + protocol dispatch + inbound/outbound channel
- StompSubProtocolHandler：CONNECT→CONNECTED、DISCONNECT→RECEIPT、MESSAGE 编码、ERROR 关闭
- StompSession 状态机：Connecting→Connected→Disconnecting→Closed，CONNECTED/ERROR/DISCONNECT
- DefaultSimpUserRegistry：user/session/subscription CRUD
- SockJS frame：open/heartbeat/message/close + go_away(3000)/another_connection(2010)
- SockJS transport handler：XHR polling/streaming/send、EventSource(data:前缀)、HtmlFile、WebSocket
- SockJS session 状态机：New→Open→Closed，initial/successive request，stream bytes limit 回收
- STOMP codec：13 命令 + header 转义 + NULL 终止 + content-length

## 五、完成定义

- 18 个 PLANNED_BLOCKED（SockJS client，依赖 vernal-http-client，记录 owner + 退出条件）
- 54 个 JAVA_ONLY_EXEMPT（Jetty/JSR-356/Servlet/XML/注解）
- 95 个测试全部通过
- `cargo fmt --check` 通过
