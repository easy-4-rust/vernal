#### 命名与组织规则

1. 目录、文件名一律 snake_case；类型 PascalCase；方法 snake_case
2. **每个 .rs 文件只对应一个 Java 类** 或 **一个 tx_di 核心概念**；接口去 Java 匈牙利前缀（`Bean`/`Aware`/`Factory` 保留 Spring 习惯）
3. `mod.rs` 只做模块声明与 re-export，**禁止定义任何类型/逻辑**
4. Java 多层嵌套包只要求**最后一层目录**完全对齐
5. 每个文件头部必须有中文 doc 注释：说明对应 Java 类的全限定名 + 对应 tx_di 模块路径 + 核心职责
6. 方法级中文注释从 Java 源码同步翻译
