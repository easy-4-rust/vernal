# spring-beans ↔ tx_di ↔ vernal-beans 功能语义迁移对照表

基线：Spring Framework **7.0.8**（spring-beans）+ tx_di（Rust DI 实证项目）。
本文档回答"功能有没有"——以 Spring 7.0.8 的语义为主轴，tx_di 的设计为副轴，
列出每个 Java 类的核心语义在 vernal-beans 中的承接方式。

迁移原则：**功能语义对齐，实现方式 Rust 化**。
Java 的反射、字节码编译、ClassLoader、CGLIB 分别映射为：
trait 对象、编译期宏、模块路径、`Arc<dyn Any>` 类型擦除。

状态图例：
- ✅ 已迁移并有测试
- ✅+🆕 已对齐语义，新文件待拆分
- 🔶 语义等价但形态不同（说明差异）
- ⬜ 未迁移（在路线图中标注）
- 🚫 不迁移（Java 生态特有）
- 🆕 Rust 侧新增
