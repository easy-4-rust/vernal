# vernal-tx 与 spring-tx 对象名称一致性检查

> 检查时间：2026-07-27
> 基线：Spring Framework 7.0.8 spring-tx
> vernal-tx：4 文件 / 88 行 / 0 测试（仅骨架）
> 目标文件数（路线图完成后）：139 文件（不含 mod.rs）

## 一、命名规范约定

| 类型 | 命名规则 | 示例 |
|------|----------|------|
| 目录/文件名 | snake_case（PascalCase → snake_case） | `PlatformTransactionManager` → `manager.rs` 或 `platform_transaction_manager.rs` |
| 类型名 | PascalCase | `PlatformTransactionManager` |
| 方法名 | snake_case | `getTransaction` → `get_transaction` |
| 枚举常量 | PascalCase | `PROPAGATION_REQUIRED` → `Propagation::Required` |
| 异常类 | 完整保留 PascalCase 命名 | `IllegalTransactionStateException` |
| trait | 保留 PascalCase，**不带 `I` 前缀** | `PlatformTransactionManager`（trait） |
| 数据结构 | 同 trait 命名 | `DefaultTransactionStatus`（struct） |

> 与 vernal-expression 一致：Java 接口的 trait 命名**不**加 `I` 前缀，与
> Spring/Java 命名一致。
