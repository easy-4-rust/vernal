# spring-jdbc + rbdc → vernal-rbdc 功能语义迁移对照表

基线（双蓝本）：
- **Spring Framework 7.0.8** `spring-jdbc` 模块（已覆盖 7.0 新增的 `JdbcClient`、`AbstractRoutingDataSource`）
- **rbdc 4.9.10**（覆盖完整 async 化 Driver/Connection/Pool 抽象）

迁移原则：**功能语义对齐，实现方式 Rust 化**。
Java 反射、字节码编译、MethodHandle、JDBC DriverManager → Rust 化为 trait 对象 + `async-trait`/`BoxFuture` + `Box<dyn Driver>` + `rbs::Value`。

状态图例：✅ 已迁移并有测试 / 🔶 语义等价但形态不同 / ⬜ 未迁移（路线图）/ 🚫 不迁移 / 🆕 Rust 侧新增
