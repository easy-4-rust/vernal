| Java `xxxCustom` / `xxxHelper` / `xxxUtils` | `CustomSQLErrorCodesTranslation` 等 | 保留类型名 |
| Java `xxxUtils` 工具类 | `JdbcUtils` / `NamedParameterUtils` | Rust 用 `pub fn` 集合在同一 `xxx_utils.rs` |
