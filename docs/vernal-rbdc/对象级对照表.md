# spring-jdbc + rbdc → vernal-rbdc 对象级对照表（验收清单）

> 检查时间：2026-07-27
> 基线（双蓝本）：
> - **Spring JDBC 7.0.8**：`/Users/wandl/workspaces/workspace-github-easy-4-rust/spring-framework/spring-jdbc`，`src/main/java` 共 **263** 个 Java 类（236 业务类 + 27 package-info 等价）
> - **rbdc 4.9.10**：`/Users/wandl/workspaces/workspace-github-easy-4-rust/rbdc`，**282** 个 Rust 文件（35 主 crate + 247 子 crate）
>
> 目标 crate：`vernal-rbdc`，文件数目标 **230+**（覆盖 Spring JDBC 263 类 + 复用 rbdc 282 文件的语义层）
>
> 本文与 `语义迁移对照表.md` 互补：语义表回答"功能有没有"，本表回答"**每个 Java 对象落在哪个 Rust 文件 / 哪个文件已存在（来自 rbdc）**"，是结构拆分与补缺的验收清单。

## 命名与组织规则

1. 目录、文件名一律 snake_case；类型 PascalCase；方法 snake_case
2. **每个 .rs 文件只对应一个 Spring JDBC 顶层 Java 对象**（package-info、`JdbcDaoSupport` 等聚合基类除外）
3. **优先直接继承 rbdc 已有的同名 trait/struct**（rbdc 文件 → vernal-rbdc 文件），并提供中文 doc 注释；不重复实现
4. Java 多层嵌套包 → 嵌套 module；最后一层目录总是对齐 Java 包路径的最后一层（`core.simple` → `core_simple`）
5. 每个文件头部必须有中文 doc 注释：说明对应 Java 类的全限定名 + Rust 化位置
6. 方法级中文注释从 Java 源码同步翻译
7. `mod.rs` 只做模块声明与 re-export，**禁止定义任何类型/逻辑**

|---|---|
| ✅ | 已迁移，独立文件已对齐 |

| 🆕 | Rust 侧新增、无 Java 对偶 |
