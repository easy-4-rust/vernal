### spring-context → vernal-context 对象级对照表（验收清单）

基线：Spring Framework **7.0.8**，spring-context 共 **约 230 个核心 Java 类**（不含
`package-info.java`，不含纯注解、纯配置、纯 XML 解析子包）。本文档与
`语义迁移对照表.md` 互补：语义表回答"功能有没有"，本表回答"**每个 Java 对象落在
哪个 Rust 文件**"，是结构拆分与补缺的验收清单。

本表只覆盖 `org.springframework.context.*` 主线（`context/`、`context/event/`、
`context/support/`、`context/i18n/`），不覆盖 spring-context 内嵌的 spring-aop、
spring-cache、spring-instrument、scheduling、jndi、jms、scripting、ui、jmx 等
子模块 —— 它们各自对应 vernal 其它 crate（如 vernal-aop、sa-token-rust 等），
不属于 vernal-context 的迁移范围。

#### 命名与组织规则

1. 目录、文件名一律 snake_case；类型 PascalCase；方法 snake_case
2. **每个 .rs 文件只对应一个 Java 对象**；接口去 Java 匈牙利前缀
3. `lib.rs` 只做模块声明与 re-export，**禁止定义任何类型/逻辑**
4. Java 多层嵌套包只要求**最后一层目录**完全对齐；vernal-context 内部按主题
   拆分子目录
5. 每个文件头部必须有中文 doc 注释：说明对应 Java 类的全限定名、核心职责
6. 方法级中文注释从 Java 源码同步翻译
