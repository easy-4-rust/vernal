# spring-context → vernal-context 功能语义迁移对照表

基线：Spring Framework **7.0.8**（spring-context 主线 + event 子包 + support 子包 + annotation 主线契约）。
已覆盖 7.0 新增的 `ContextPausedEvent` / `ContextRestartedEvent` / `SmartLifecycle#isPauseable`
语义；配置/启动阶段由 vernal-beans + vernal-aop 共同承担，本表不重复。

迁移原则：**功能语义对齐，实现方式 Rust 化**。
Java 的反射 → trait 对象；AnnotationProcessor → 过程宏 + linkme；JVM shutdown hook
→ Tokio signal listener；J.U.C Executor → tokio::runtime::Handle；Aware 注入 →
IoC 显式依赖注入。

参考：`vernal-beans` 承担 `BeanFactory` / `BeanDefinition` / `Scope` / `Qualifier` /
`TraitBinding` 等"bean 工厂"语义；`vernal-aop` 承担 `Advisor` / `Pointcut` /
`InvocationPlan` 等 AOP 语义；`vernal-expression` 承担 `Expression` / `SpEL`
/ `@ConditionalOnExpression` 求值语义。**vernal-context 只做"装配 + 编排"**。

状态图例：✅ 已迁移并有测试 / 🔶 语义等价但形态不同 / ⬜ 未迁移（路线图）/ 🚫 不迁移（生态特有）/ 🆕 Rust 侧新增

## 一、应用上下文门面

| Java 接口 | 语义 | Rust 实现 | 状态 |
|---|---|---|---|
| ApplicationContext | 中央门面，提供 BeanFactory / Environment / EventPublisher / ResourceLoader / i18n | `ApplicationContext` struct（仅承载 BeanFactory + Environment + EventBus；不暴露 ResourceLoader / i18n） | ✅ |
| ConfigurableApplicationContext | refresh / close / 注册 BeanFactoryPostProcessor / 注册监听器 / 设置 Environment / 设置 ApplicationStartup | `ApplicationContextBuilder` + `VernalApplicationBuilder` + `application_startup_coordinator` / `application_close_coordinator` | ✅ |
| ApplicationContextAware | 注入 ApplicationContext | 🚫 Rust 由 `resolver.resolve::<ApplicationContext>()` 直接依赖 | 🚫 |
| ApplicationContextInitializer | 在 refresh 之前回调 | 🔶 由 `VernalApplicationBuilder::register_module` 与 `lifecycle` 钩子替代 | 🔶 |
| ApplicationContextException | 上下文异常基类 | `ContextError` enum + `ApplicationBuildError` + `ApplicationLaunchError` + `ApplicationModuleError` | ✅ |
| getId / getApplicationName / getDisplayName / getStartupDate / getParent | 上下文元数据 | 🔶 由 `StartupReport` 汇总；id/parent 暂不暴露 | 🔶 |
| getAutowireCapableBeanFactory | 暴露 AutowireCapableBeanFactory | `ApplicationContext::container() -> &Container` | ✅ |
