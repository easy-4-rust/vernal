## 检查规则

1. Java 类型名保持 PascalCase；Rust 文件名按缩写感知的 snake_case 转换。
2. Java 包去掉组织与模块根包后保留末两层。
3. 同名但路径错误记 `MISPLACED`，不允许记“形态等价”。
4. Rust 同一文件多个 Spring 主对象违反单文件单对象规则。
5. 缺少中文 `对应 Java:` 注释或语义测试时记 `UNVERIFIED`。
6. `lib.rs`、`mod.rs` 中定义业务类型属于结构红线。

## 已知结构问题

自动报告记录 10 个错位对象，并记录 `properties_file.rs`、`ordered.rs`、
`converter_registry.rs`、`generic_converter.rs`、`mime_type.rs` 等文件存在多个公开对象。
这些问题必须在补缺之前先完成路径和文件拆分。
