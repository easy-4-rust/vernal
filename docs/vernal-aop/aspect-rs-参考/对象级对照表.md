## 命名与组织规则

1. 目录、文件名一律 snake_case；类型 PascalCase；方法 snake_case
2. **每个 .rs 文件只对应一个 aspect-rs 对象**（或一组紧密相关的 trait）
3. `mod.rs` 只做模块声明与 re-export，**禁止定义任何类型/逻辑**
4. 移植时**保留原类型语义**，但可改名以避免与现有 vernal-aop 冲突
5. 每个文件头部中文 doc 注释：说明对应 aspect-rs 源文件、核心职责、改造点

## 命名冲突规避（关键）

aspect-rs 与 vernal-aop 现有类型存在多处同名，移植时**必须改名**：

| aspect-rs 原名 | vernal-aop 移植名 | 冲突原因 |
|---|---|---|
| `Pointcut`（AST enum）| `PointcutExpr` | vernal-aop 现有 `Pointcut` trait（基于 Operation）|
| `Matcher` trait | `PointcutMatcher` | 避免歧义 |
| `FunctionInfo` | `FunctionDescriptor` | 避免与 `Operation` 混淆 |
| `parse_pointcut` | `parse_pointcut_expr` | 强调解析表达式 |
| `Aspect` trait | **不移植** | 与现有 `Interceptor`（Around）语义冲突 |
| `ProceedingJoinPoint` | **不移植** | 用现有 `Next`（已等价）|
| `JoinPoint` | **不移植** | 用现有 `Operation`（更通用）|
| `Location` | **不移植**（作为 Operation 元数据补充）| 可选 |

## 1. aspect-core：核心抽象（aspect.rs + joinpoint.rs + error.rs）

### 1.1 Aspect trait（aspect.rs，1 类 → 不移植）

| aspect-rs 类 | 目标 | 状态 | 说明 |
|---|---|---|---|
| `Aspect` trait（before/after/after_error/around 同步）| 🚫 不移植 | 🚫 | vernal-aop 用 `Interceptor`（异步 Around）为主，同步 Advice 由 S1 新增的 `MethodBeforeAdvice`/`AfterReturningAdvice`/`ThrowsAdvice` 承载 |

**理由**：aspect-rs 的 `Aspect` 是同步四段式（before/after/after_error/around 默认实现），
vernal-aop 是 Tokio-first 异步 Around。强行移植会破坏异步语义。aspect-rs 的 `Aspect`
**仅作为 S1 Advice 体系的形态参考**（验证 before/after/after_error 三段式可行），
不直接移植代码。

### 1.2 JoinPoint 体系（joinpoint.rs，3 类 → 不移植）

| aspect-rs 类 | 目标 | 状态 | 说明 |
|---|---|---|---|
| `JoinPoint`（function_name/module_path/location）| 🚫 用现有 `Operation` | 🔶 | Operation（component/method/metadata）更通用 |
| `Location`（file/line 静态位置）| 🚫 作为元数据 | 🔶 | 可选加入 OperationMetadata |
| `ProceedingJoinPoint`（proceed() 控制执行）| 🚫 用现有 `Next` | 🔶 | `Next::run()` 已等价 |

**理由**：vernal-aop 的 `Operation` + `Next` 比 aspect-rs 的 `JoinPoint` +
`ProceedingJoinPoint` 更强大（Operation 支持 tags/qualifiers，Next 是异步 Future）。
aspect-rs 这 3 个类**仅作概念参考**。

### 1.3 错误体系（error.rs，1 类 → 🔶 参考）

| aspect-rs 类 | 目标 | 状态 | 说明 |
|---|---|---|---|
| `AspectError`（ExecutionError/WeavingError/Custom）| 🔶 参考 | 🔶 | vernal-aop 用 `InvocationError`（现有），可补充 `WeavingError` 变体 |

**aspect-rs AspectError 变体**（参考价值）：

| 变体 | 字段 | vernal-aop 对应 |
|---|---|---|
| `ExecutionError` | message: String, source: Option<Box<dyn Error>> | 现有 `InvocationError` 已覆盖 |
| `WeavingError` | message: String | 🆕 可补充（织入阶段错误）|
| `Custom` | Box<dyn Error> | 现有 `InvocationError` 已覆盖 |

**aspect-rs 构造方法**（参考价值）：

| 方法 | vernal-aop 对应 |
|---|---|
| `AspectError::execution(impl Into<String>)` | 现有 `InvocationError::new` |
| `AspectError::execution_with_source(msg, source)` | 现有 `InvocationError::with_source` |
| `AspectError::weaving(impl Into<String>)` | 🆕 可补充 |
| `AspectError::custom(error)` | 现有 `InvocationError::from` |

**Matcher → PointcutMatcher 改造**：

```rust
// aspect-rs 原版
pub trait Matcher {
    fn matches(&self, function: &FunctionInfo) -> bool;
}

// vernal-aop 移植版
pub trait PointcutMatcher {
    /// 匹配 vernal-aop 的 Operation（而非 aspect-rs 的 FunctionInfo）
    fn matches_operation(&self, operation: &Operation) -> bool;
}
```

**改造说明**：`PointcutMatcher::matches_operation` 接收 vernal-aop 现有的 `Operation`
（含 component/method/metadata/tags/qualifier），内部转换为 `FunctionDescriptor`
进行匹配。这样既复用 aspect-rs 的匹配逻辑，又接入 vernal Operation 体系。

| 熔断 | （无）| `circuitbreaker` | **aspect-rs 独有**（🆕 failsafe）|
| 授权 | （无）| `authorization` | **aspect-rs 独有**（🆕）|
| 校验 | （无）| `validation` | **aspect-rs 独有**（🆕 validator）|

**结论**：aspect-std 的 caching/circuitbreaker/authorization/validation 是 spring-aop
**完全没有的业务切面**，直接补强 vernal-aop S5 阶段。

### 4.2 aspect-std 切面的 Rust crate 依赖

| aspect-std 切面 | 推荐的 Rust crate | 说明 |
|---|---|---|
| `caching_aspect` | `moka`（LRU/TTL 缓存）| 并发安全、高性能 |
| `circuitbreaker_aspect` | `failsafe-rust` 或自实现状态机 | 熔断（closed/open/half-open）|
| `ratelimit_aspect` | `governor`（令牌桶）| 限流 |
| `validation_aspect` | `validator` crate | 校验（用户提供的 crate 清单已包含）|
| `logging_aspect` / `timing_aspect` / `metrics_aspect` | `tracing` | 日志/计时/度量 |
| `authorization_aspect` | 自定义（闭包）| 业务逻辑 |

## 附录：aspect-rs 与 spring-aop 概念映射（三方对照）

下表展示 aspect-rs 如何桥接 spring-aop 与 vernal-aop：

| 概念 | spring-aop | aspect-rs | vernal-aop |
|---|---|---|---|
| 切点 | `Pointcut`（ClassFilter + MethodMatcher）| `Pointcut` AST（Execution/Within）| `Pointcut` trait（Operation）+ 🆕 `PointcutExpr` AST |
| 切点表达式 | AspectJ 表达式（execution/within/args/this/target）| `execution()` / `within()` + `&&/\|\|/!` | 🆕 移植 aspect-rs + 扩展 `tag`/`qualifier` |
| 通知（前置）| `MethodBeforeAdvice` | `Aspect::before` | S1 新增 `MethodBeforeAdvice` |
| 通知（后置）| `AfterReturningAdvice` | `Aspect::after` | S1 新增 `AfterReturningAdvice` |
| 通知（异常）| `ThrowsAdvice` | `Aspect::after_error` | S1 新增 `ThrowsAdvice` |
| 通知（环绕）| `MethodInterceptor` | `Aspect::around` | 现有 `Interceptor`（异步）|
| 连接点 | `JoinPoint` / `MethodInvocation` | `JoinPoint` + `ProceedingJoinPoint` | `Operation` + `Invocation` + `Next` |
| 切点匹配器 | `MethodMatcher` | `Matcher` trait | 🆕 `PointcutMatcher` |
| 函数信息 | `Method`（反射）| `FunctionInfo` | 🆕 `FunctionDescriptor` + `Operation` |
| 声明式绑定 | `@Aspect` + `@Pointcut` 注解 | `#[advice(pointcut=...)]` 宏 | 🆕 `#[advice]` 宏（A2）|
| 错误 | `AopInvocationException` | `AspectError`（ExecutionError/WeavingError/Custom）| 现有 `InvocationError` + 🆕 `WeavingError` |
| 业务切面 | （无，仅调试工具）| aspect-std 8 个切面 | 🆕 A3 移植 8 个业务切面 |

**核心价值**：aspect-rs 是 spring-aop 概念的 Rust 原生实现，vernal-aop 通过移植
aspect-rs 的 Pointcut DSL + aspect-std 业务切面，**以最小代价获得 spring-aop 的
Rust 原生等价物**，同时保持自己的异步 + 预编译优势。
