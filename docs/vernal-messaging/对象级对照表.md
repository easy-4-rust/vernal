# spring-messaging → vernal-messaging 对象级对照表（验收清单）

基线：Spring Framework **7.0.8** `spring-messaging` 共 **245 个 Java 文件**。
本文档与 `语义迁移对照表.md` 互补：语义表回答"功能有没有"，
本表回答"**每个 Java 对象落在哪个 Rust 文件**"，是结构拆分与补缺的验收清单。

## 命名与组织规则

1. 目录、文件名一律 snake_case；类型 PascalCase；方法 snake_case
2. **每个 .rs 文件只对应一个 Java 对象**（或一组紧密相关的 trait）
3. `mod.rs` 只做模块声明与 re-export，**禁止定义任何类型/逻辑**
4. Java 多层嵌套包只要求**最后一层目录**完全对齐
5. 每个文件头部必须有中文 doc 注释

## 九、ddd4r 集成对照

### 9.1 ddd4j-mq-core 核心 API（Java）

| Java 接口 | 语义 | vernal-messaging 桥接 |
|---|---|---|
| `MQClient` | 统一 broker 客户端 SPI | `support/ddd4r_integration.rs` 桥接 |
| `MQEvent` | 统一事件格式（topic + tags + body + headers） | 映射到 `Message<Payload>` |
| `MQEventListener` | 事件监听器注解 | 映射到 `#[message_handler]` 宏 |
| `MQProperties` | broker 配置（14 种 BrokerType） | 映射到 `ConfigurationProperties` |
| `Acknowledgment` | 消息确认（ack/nack/reject） | 映射到 `Acknowledgment` trait |
| `MessageHeaders` | 消息头（8 个标准 key） | 映射到 `MessageHeaders` struct |
| `TagMatcher` | 标签匹配器 | 映射到 `TagExpression` + `RouteMatcher` |

### 9.2 ddd4r-mq-core 核心 API（Rust）

| Rust trait | 语义 | vernal-messaging 桥接 |
|---|---|---|
| `MessagePublisher` | 异步消息发布（publish → PublishReceipt） | `MessageChannel::send` 等价 |
| `MessageHandler` | 异步消息处理（handle → HandlerOutcome） | `MessageHandler::handle_message` 等价 |
| `MessageStore` | 事件存储（save/load） | Outbox 模式支持 |
| `Subscription` | 订阅配置（topic + tag_expression） | `SubscribableChannel::subscribe` |
| `Acknowledgment` | 确认 trait（settle(AckCommand)） | `ChannelInterceptor::after_completion` |
| `ConsumerEngine` | 至少一次 + 幂等消费引擎 | `ManagedTaskSupervisor` 驱动 |
| `TagExpression` | SQL-92 选择器表达式 | `DestinationPatternsMessageCondition` |
