### spring-messaging → vernal-messaging 对象级对照表

> 基线：Spring Framework 7.0.8 `spring-messaging`。本表按包和对象族列出迁移落点；协议、Reactive、模板与注解不再以“排除”表示，而以 feature/独立 crate 记录。
> 状态：✅ 已实现｜⬜ 待实现｜🔶 Rust 形态不同但需保持语义｜🧩 feature/companion crate｜🆕 Rust 新增｜🔌 外部桥接（不进核心）。

#### 一、目标 crate 与统计口径

| 层 | 目标 | 是否属于核心 |
|---|---|---:|
| `vernal-messaging` | Spring Messaging 核心合同与默认实现 | 是 |
| `vernal-messaging` `reactive` feature 或 `vernal-messaging-reactive` | Reactive handler、流、背压、取消 | 可选 companion |
| `vernal-stomp` | STOMP frame、session、broker、用户目的地 | 否，协议 companion |
| `vernal-rsocket` | RSocket service、metadata、交互模型 | 否，协议 companion |
| `vernal-messaging-tcp` | TCP transport、codec、连接生命周期 | 否，transport companion |
| `ddd4r-vernal-messaging` | ddd4r 事件、发布、消费、确认、生命周期桥接 | 否，外部集成 |

对象统计采用“Java 对象族 + Rust 落点”口径。一个 Rust 文件可以承载紧密相关对象，但不得因此丢失单项语义或测试 oracle。
