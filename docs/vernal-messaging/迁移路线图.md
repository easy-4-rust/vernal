# vernal-messaging 全量迁移路线图

> 版本：v1.0（2026-07-26）
> 基线：Spring Framework **7.0.8** spring-messaging（245 个 Java 文件，需迁移 45 个）
> 整合：ddd4j / ddd4r MQ 模块（14 种 broker）
> 本文档随代码同步维护，每阶段完成时更新

## 一、总目标

以 Spring Framework 7.0.8 的 spring-messaging 为蓝本，实现 ddd4r/ddd4j 友好的
vernal-messaging crate，通过 ddd4r-mq-core 间接支持 14 种 broker。

### 硬性规范

1. 一文件一对象（与 vernal-expression 保持一致）
2. 目录/文件名 snake_case；类型 PascalCase；方法 snake_case
3. `mod.rs` 只做模块声明 + re-export，禁止定义类型
4. 全中文文档注释（对应 Java 类全限定名 + 核心职责）
5. **ddd4r 集成优先**：ConsumerEngine / MessagePublisher / TagExpression 必须桥接

### 依赖方向（不可违反）

```
vernal-event（事件总线）
  ↓ EventBusBridge
vernal-messaging（消息通道抽象）
  ↓ ddd4r_integration
ddd4r-mq-core（消费者、路由、确认、幂等）
  ↓ trait 实现
14 种 broker provider crate
```
