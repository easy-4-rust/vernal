# spring-messaging → vernal-messaging 功能语义迁移对照表

基线：Spring Framework **7.0.8** `spring-messaging`（245 个 Java 文件）。
本表回答"**功能有没有**"，与 `对象级对照表.md` 互补。

迁移原则：**功能语义对齐，实现方式 Rust 化**。
Java 的 Spring 容器 + JMS → 显式注册表 + tokio mpsc channel；
Java 反射 → Rust trait 对象；Java ExecutorService → tokio::spawn。

状态图例：✅ 已迁移并有测试 / 🔶 形态不同 / ⬜ 未迁移 / 🚫 不迁移

## 七、ddd4r 集成对照（核心重点）

### 7.1 消息模型映射

| ddd4r (Rust) | vernal-messaging | 说明 |
|---|---|---|
| `MqEvent`（topic + tags + body + headers） | `Message<Vec<u8>>` | payload = body，headers 含 topic/tags |
| `MessageHeaders`（8 个标准 key） | `MessageHeaders` | 直接映射 |
| `Delivery`（投递元数据） | `MessageHeaders` 中的扩展头 | 合并 |
| `HandlerOutcome`（处理结果） | `MessageDeliveryResult` | Sent/Failed/Ack/Nack |
| `PublishReceipt`（发布回执） | `MessageDeliveryResult::Sent` | 含 offset/messageId |
| `TopicAddress`（topic + optional namespace） | `String`（Destination） | 字符串编码 |
| `Subscription`（topic + tag_expression） | `SubscribableChannel` + filter | 订阅配置 |

### 7.2 核心桥接

| ddd4r trait | vernal-messaging 等价 | 说明 |
|---|---|---|
| `MessagePublisher` | `MessageChannel::send` | 异步 publish → sync send + DeliveryResult |
| `MessageHandler` | `MessageHandler::handle_message` | 直接对齐（async → async） |
| `Acknowledgment` | `ChannelInterceptor::after_completion` | settle(Ack) → 拦截器回调 |
| `ConsumerEngine` | `ManagedTaskSupervisor` 驱动 | 消费循环注册为 AsyncTask |
| `IdempotencyStore` | 外部组件（不内建） | 通过 IoC 注入 |

### 7.3 14 种 Broker 支持

vernal-messaging **不直接实现任何 broker SDK**。
通过 ddd4r 的 provider crate 间接支持：

```
vernal-messaging（统一抽象）
  ↓ ApplicationModule 注册
ddd4r-mq-core（ConsumerEngine + MessagePublisher trait）
  ↓ trait 实现
ddd4r-mq-provider-kafka / redis-streams / pulsar / ...
```
