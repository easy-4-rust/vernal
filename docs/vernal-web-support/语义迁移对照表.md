> CodeGraph 证据：MVC 为 `DispatcherServlet#doDispatch → HandlerMapping → HandlerAdapter →
> HandlerExceptionResolver`；WebFlux 为 `DispatcherHandler#handle → HandlerMapping →
> HandlerAdapter → HandlerResultHandler`。

| 调用链 | Rust 分层目标 | 状态 |
|---|---|---|
| MVC 同步分派 | runtime route → invocation → response mapper | `PLANNED` |
| WebFlux reactive 分派 | async route → future/stream → result handler | `PLANNED` |
| CORS/preflight | 共用策略 + runtime header adapter | `PLANNED` |
| 异常解析 | `WebFailure`/`ProblemDetails` + runtime response | `PARTIAL` |

不得把框架路由本身等同于 Spring `HandlerMapping` 的完整注册、排序和匹配语义。

## Java 到 Rust 技术语义

| Java 机制 | Rust 映射 | 验证重点 |
|---|---|---|
| nullable | `Option<T>` | `None` 与空值不得混同 |
| checked exception | `thiserror` + `Result<T, E>` | 分类、cause 和上下文 |
| synchronized/并发容器 | `Arc<RwLock<_>>`/`DashMap` | 竞争、可见性和死锁 |
| CompletableFuture | `Future`/`JoinHandle` | 完成、失败、取消和超时 |
| Reactor Mono | `async fn -> Result<T, E>` | 单值、空结果和错误 |
| Reactor Flux | `Stream<Item=Result<T,E>>` | 背压、顺序、取消和终止 |
| ServiceLoader | `inventory` + registry | 自动注册和确定性 |
| JVM/字节码 | 有证据才可 `PLATFORM_NA` | 困难不等于不适用 |
