## 六、特殊命名决策记录

### 6.1 同名冲突处理

| 冲突 | 解决方案 |
|------|---------|
| rbatis 内置 `CacheIntercept` vs rbatis-cache `CacheInterceptor` | 取后者（rbatis-cache 命名更标准），rbatis 内置版本合并到 `cache_interceptor.rs` |
| rbatis 内置 `CacheKey` vs rbatis-cache `CacheKey` | 取后者（BLAKE3 摘要版本功能更强），rbatis 内置版本合并 |
| rbatis 内置 `CachePolicy` vs rbatis-cache `CachePolicy` | 取后者（含 InvalidationStrategy 字段），rbatis 内置版本合并 |

### 6.2 RBatis 前缀保留

源对象 `RBatis*` 在 vernal-rbatis 中**保留 RBatis 含义但去除文件名前缀**：

- `RBatisConnExecutor` → `conn_executor.rs`（**模块路径内显式属于 rb 模块**，无需重复前缀）
- `RBatisTxExecutor` → `tx_executor.rs`
- `RBatisTxExecutorGuard` → `tx_executor_guard.rs`
- `RBatis` → `rb.rs`

但**类型名仍保留** `RBatisConnExecutor`（PascalCase）以保持与源对象的语义对齐。

### 6.3 Spring 前缀替换

源对象 `Spring*` 在 vernal-rbatis 中**替换为 `Rb*`**：

- `SpringSessionSynchronization` → `RbTransactionSynchronization`
- `SpringSessionContext` → 整合到 `integration::tx_integration`
- `SpringBeanContainer` → 不迁移（由 vernal-context 替代）
- `SpringFlushSynchronization` → 合并到 `RbTransactionSynchronization`

### 6.4 Hibernate / JPA 前缀处理

源对象 `Hibernate*` / `Jpa*` 在 vernal-rbatis 中**统一为 `Rb*`**：

- `HibernateTransactionManager` → `RbTransactionManager`
- `JpaTransactionManager` → `RbTransactionManager`（合并）
- `HibernateExceptionTranslator` → `RbExceptionTranslator`
- `JpaDialect` → `RbExceptionDialect`
- `JpaSystemException` → `RbSystemException`
- `JpaObjectRetrievalFailureException` → 合并到 `optimistic_lock.rs`

### 6.5 缓存命名冲突处理

| 源 | vernal-rbatis | 说明 |
|----|---------------|------|
| rbatis 内置 `CacheIntercept` | 合并到 `cache_interceptor.rs` | 不单独命名 |
| rbatis-cache `CacheInterceptor` | `cache::cache_interceptor::CacheInterceptor` | 取此命名 |
| rbatis `TransactionalCacheBuffer` | `cache::transactional_buffer::TransactionalCacheBuffer` | 命名一致 |
| rbatis `CacheTransactionListener` | `cache::cache_listener::CacheTransactionListener` | 命名一致 |

## 七、整体一致性结论

| 维度 | 评估 | 说明 |
|------|------|------|
| 命名一致率 | 64 / 149 = **43.0%** | 完全匹配；其余合并/不迁移/扩展 |
| 模块路径一致率 | 11 / 11 = **100%** | 所有源模块都有对应目录 |
| 跨源命名冲突 | **3 处** | 全部已解决 |
| 不一致对象分类 | 35 不迁移 + 12 合并 + 4 扩展 | 结构清晰 |
| 整体健康度 | ✅ | 无未识别的源对象 |

> 与 vernal-expression 迁移对比：vernal-expression 完全匹配率约 67%（79/117）；
> vernal-rbatis 完全匹配率约 43%（64/149），但**总对象数更多（149 vs 117）**，
> 合并率与不迁移率也更高（合计 47 vs 38），反映了 rbatis + rbatis-cache + spring-orm 三源合并时
> 的对象重复（如 `CacheKey` / `CachePolicy` / `CacheInterceptor` 在 rbatis 与 rbatis-cache 各有一份）。
