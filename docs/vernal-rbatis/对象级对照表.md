#### 3. 命名与组织规则

1. 目录、文件名一律 snake_case；类型 PascalCase；方法 snake_case
2. **每个 .rs 文件只对应一个核心源对象**（rbatis / rbatis-cache / spring-orm 任一）
3. `mod.rs` 只做模块声明与 re-export，**禁止定义任何类型/逻辑**
4. Java 多层嵌套包只要求**最后一层目录**完全对齐；spring-orm 的 `jpa.hibernate` 路径在 Rust 简化为 `tx/`（与事务集成层合并）
5. 每个文件头部必须有中文 doc 注释：说明对应源对象的全限定名、核心职责
6. 方法级中文注释从源对象同步翻译
7. 同名冲突（rbatis 的 `CacheInterceptor` 实际并不存在，rbatis-cache 的 `CacheInterceptor` 是同名）：以 rbatis-cache 为准命名 `cache_interceptor.rs`
